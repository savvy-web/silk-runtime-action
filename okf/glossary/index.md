# Glossary

* [Legacy / v1 / oracle N / ruling N / quirk N citations](legacy-v1-citations.md) - Provenance labels scattered through src/ comments that cite a pre-rebuild tree this repository does not carry — the prose beside each label is the authority, never the number.
* [Parity surface](parity-surface.md) - What a consumer observes and this repository's tests pin verbatim — action.yml's inputs and outputs, plus the exact log and job-summary prose — as distinct from internal shapes that are free to change.
* [Seam](seam.md) - In this repository, a seam is a defaulted parameter that stands in for a kit static or a process read, never a repository-local service — a narrower sense than the wider ecosystem's usage.
